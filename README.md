# Mod Executor

Aplicativo Android educacional com botão flutuante, editor Lua, IA amiga e sessão de 10 minutos.

A execução de Lua é limitada a um sandbox/local ou ao próprio projeto Roblox Studio do desenvolvedor. O projeto não injeta código nem contorna proteções do cliente normal do Roblox.

## Build

O workflow em `.github/workflows/android.yml` compila o APK Debug no GitHub Actions.
