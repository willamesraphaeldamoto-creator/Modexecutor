# Jarvis (Android)

1. Suba esta pasta num repositório do GitHub (branch `main`).
2. Aba **Actions → Build Jarvis APK** roda sozinha. Baixe `jarvis-apk` em *Artifacts*.
3. Instale o APK, abra o app e faça os passos 1 a 5 na tela.
4. Cole a chave do OpenRouter e toque em "Baixar modelo" para o modelo local.

Para release público: `git tag v1.0 && git push --tags`.
